为什么是词屿

把读、查、背、练、说，放进一个窗口

不追求花哨的排行榜，只把「今天该复习哪几个词」「这篇外刊怎么读完」「这句英语怎么说」做顺。

说

口语对练 3.9.56 新增

左侧打开「口语对练」，点「开始通话」就能用英语自由聊天：本地识别、小屿语音回复，可静音、挂断或在小屿回复时点「我来说」接过话轮。挂断后能点最后一句旁的「纠正上一句」，改完听写再让它重新接话。

一句话情景练习

常见问题

你可能想问的

免费吗？

目前个人使用免费。商业使用或二次分发请联系站点邮箱说明用途；源码许可见仓库的 LICENSE。

安装版和绿色版有什么区别？

安装版会有桌面 / 开始菜单快捷方式和卸载入口，默认装到 %LOCALAPPDATA%\Programs\WordIsle；绿色版解压后直接双击 WordIsle.exe，不写安装记录。两者的功能、数据目录和账号完全一致，升级都保留学习记录。

下载按钮跳到哪了？

跳到 GitHub Releases 的固定直链：安装包 releases/latest/download/WordIsle-3.9.56-preview-Setup-x64.exe，绿色版 releases/latest/download/WordIsle-3.9.56-preview-win-x64.zip。如果浏览器拦截了跳转，也可以直接打开 Releases 页面 手动下载。

离线增强包怎么装？

下载全部 3 个分卷（.001 / .002 / .003），放在同一目录，用 7-Zip 打开 .001 解压，得到「词屿离线增强包」文件夹。把它和词屿的程序文件夹放在同一个父目录下（例如 D:\词屿离线增强包 与 D:\词屿体验版 并列），重新打开词屿即可使用 Qwen3-4B 伴学、Hy-MT2 翻译与增强听写。缺少分卷时无法完整解压。

和旧的 3.9.3 安装版数据互通吗？

使用独立数据目录 %APPDATA%\WordIsle-Contest-Preview，默认不读写旧版的学习记录。需要迁移时，可在注册时勾选迁入旧版本机记录，或先在旧版「设置 → 导出学习 JSON」再导入。

需要联网吗？

核心功能（词书、查词、全文阅读、练习、复习、本地 AI）完全离线。在线朗读、外刊更新与「原站全文」需要网络；断网时朗读回退系统语音，已缓存的正文照常可读。检查更新只读取 version.json，不会上传本机数据。

学习数据会上传吗？

不会。注册的是本机账号，学习进度、生词本、笔记与设置加密保存在本机，不上传账号服务器、不自动跨设备同步。本地 AI 推理不外发资料；只有主动选择在线 API 模式时才按界面中的发送确认发出。

为什么 Windows 提示「未知发布者」？

可执行文件没有购买 CA 代码签名证书。选择「更多信息 → 仍要运行」即可；要彻底消除提示需要购买 OV/EV 代码签名证书。

有 macOS 版吗？

源代码已适配 macOS（双架构、标准菜单、DMG 配置），但安装包必须在 Mac 上构建。项目里提供了 build-macos.sh 与 GitHub Actions 工作流，可自行生成 DMG。

词书可以自定义吗？

可以。词书广场可新建 / 删除个人词库；设置支持导入 XLSX、TXT、CSV 或 JSON（Excel 读取第一个工作表，至少含「单词」「释义」两列），也可以把查词时收藏的词当普通词库练习。

会收集使用统计吗？

当前不接入任何统计或广告脚本。如果之后启用隐私友好的访问统计，会在本页说明。
