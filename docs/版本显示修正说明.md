# 3.9.22-preview 版本显示修正

截图中的运行包实际版本为 3.9.21-preview，设置页却在“当前版本”下面展示了远端更新清单的 3.9.3。底部提示读取的是本机版本，因此出现两处不一致。

当前修正版是 3.9.22-preview，修正如下：

- “当前运行版本”通过本地 IPC 读取 Electron 的 `app.getVersion()`，以运行包的 package.json 为来源；不会把远端版本号填进本机版本一栏。
- 在不联网、不启用自动检查、尚未检查更新、更新检查失败时，本机版本仍正常显示。版本信息不写入学习备份，重新启动会读取当前运行包的信息。
- 公开清单版本另列，区分较旧、相同和较新三个情况；清单较旧时不显示降级下载入口，也不会将其标成当前版本。
- 更新提示与页面使用相同的比较规则，区分预览版、正式版和数字预发布后缀；相同基础版本的正式版高于预览版，构建标记不影响顺序。
- 更新请求最长约 12 秒，超时会结束检查并保留本机版本显示。是否下载与安装仍由用户决定。

通过纯版本比较及实际更新处理器测试，覆盖旧清单、相同版本、较新版本、预览转正式、数字后缀、非法版本、HTTP 错误、离线及超时。另在实际桌面窗口中核对了本机 IPC 返回值与运行包版本一致，复现 3.9.3 清单后的页面、提示与下载入口，并检查重启及 390 / 1280 像素布局。

《版本显示修正.png》使用旧清单数据复现问题后的修正界面；实际联网结果以当时的公开清单为准。此修正沿用现有用户数据目录，保留学习记录、词书、助记、资料和设置。
