# 词屿 3.9.28：新手引导与答题音效

## 四选一即时反馈

英文选义、中文选词、听音选择共用答题反馈：答对播放轻快的上扬音，答错播放柔和的下行音，并继续显示正确答案。声音在本机合成，不需要网络或下载音效；每次答题只播放一次，重复点击不会重复计分或叠加声音。

在“设置 → 音效与使用帮助”可开启或关闭“四选一答题音效”、调整音量和分别试听。初始音量为 35%，安静模式统一静音；关闭声音或设备暂时不能播放时，文字和颜色反馈仍正常显示。提示音音量独立于单词发音音量。

## 新账号四步引导

注册并保存恢复密钥、进入自己的学习空间后，自动显示简短的新手引导：

1. 认识首页与基本学习路线。
2. 选择词书和每日 1—300 个新词目标；点击下一步才保存本步选择。
3. 体验一道四选一，熟悉答题、音效、键盘 1—4 及中断续学。体验题不计入学习记录，也不改变复习安排。
4. 了解 AI 伴学、实时听译和离线查词，再选择开始学习或先看看首页。

每一步右上角均有“跳过引导”，欢迎页也可直接选择“我很熟悉，直接进入”；Esc 同样可以跳过。体验题不必作答即可进入下一步。完成或跳过后按账号保存状态，下次登录不再自动出现，清空学习记录也不会重新要求引导。

旧版本已注册账号升级后不会自动弹出引导。所有账号都可以在“设置 → 音效与使用帮助 → 新手引导 → 重新查看”主动重看；重看支持随时退出。

## 验证范围

使用独立测试账号验证了首次出现、完成和跳过后的重新登录、旧版账号升级、设置重看、学习计划保存、演示题不计分、真实选择题音效、重复点击保护、安静模式及音量保存，并检查了 390 和 1280 像素宽度下的界面。

通过离线音频渲染确认答对和答错产生不同、非零且不削波的波形。已有中断续学、复习曲线、真实离线 AI 讲解与语音识别也通过回归检查。此验证不代表所有声卡、音箱或听觉条件下的实际听感测试；具体记录见“验证数据/新手引导与音效验证.json”。
