# 登录偏好 · 3.9.26-preview

登录页采用头像、账号密码输入区和并排勾选项的熟悉布局，保留词屿自己的图形与青春配色，未使用 QQ 的图标或品牌素材。

- 记住密码：默认关闭，勾选并成功登录后，用系统加密保存最近一个账号的登录凭据。正常关闭再打开，账号自动填入，密码显示圆点占位，点击登录即可。
- 自动登录：默认关闭，勾选会同时选择记住密码；正常关闭后再次启动自动进入，进入前有取消按钮。取消自动登录后保留记住密码，供主动点击登录。
- 取消记住密码：立即删除保存的凭据，同时关闭自动登录；无需等到下次登录。
- 退出账号：关闭自动登录，保留记住密码；手动锁定和 Windows 锁屏：保留选择，但暂停保存凭据的使用并要求输入密码，暂停状态跨重启生效。
- 改密、密码恢复及切换账号：清理旧凭据。设置页也有清除按钮。

安全存储位于用户数据目录的 remembered-login.json，文件只保存版本、加密类型和密文；真实密码不写入明文、不回传登录页面。系统保护无法使用时不做明文降级，仍可手动登录。账号的 scrypt 与 AES-256-GCM 数据加密沿用原实现，密码最低 9 位。

通过正常 Windows 用户上下文的独立测试账号验证了：系统加密、默认不勾选和联动、重启恢复、正常关闭后自动进入、取消自动登录、账号绑定、锁定和锁屏、改密清理、立即取消记住及 390/1280 布局。沙盒隔离用户配置时，系统加密不可用的回退也已检查。报告见“验证数据/登录偏好验证.json”。

依据：[Electron safeStorage 官方文档](https://www.electronjs.org/docs/latest/api/safe-storage)。Windows 保护依赖当前 Windows 用户身份，同一身份下的其他程序和已解锁电脑的使用者不属于隔离范围；请在自己的电脑上开启。
