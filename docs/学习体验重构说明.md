# 学习体验重构 · 3.9.27-preview

本轮围绕“打开软件 → 知道今天学什么 → 专注完成一组 → 中断后继续 → 在语境中运用”重组体验。保留词屿的青春配色、原创伙伴、离线字典、内置模型与实时听译，把常用操作放在前面，说明和参数按需展开。

## 现在怎样使用

首页的主按钮会根据状态显示开始或继续。默认每组最多 10 词，先安排到期复习，再取每日剩余额度内的新词；每日目标仍为 1—300。词书和目标在“调整计划”里设置，练习方式在“更多练习与我的节奏”中选择。原有 42 本词书、自定义词库及跨词书进度继续使用。

学习时默认进入专注模式，收起导航与重复统计，不用等待动画结束即可作答。可用“显示导航”退出专注界面，或用“暂存并离开”和 Esc 暂停。个人助记、输入草稿、当前题型、选择题选项及已答状态都会随本轮保存；小循环已提交的复习安排在恢复后不会重复计入。页面会显示保存状态，失败时仍会提示。

当前账号保留一轮未完成练习。离开去查词、听译或伴学后，可通过返回学习条继续；主动开启其他练习会切换本轮，已经提交的学习记录保留。续学数据与学习记录一并写入本机加密账号，不新增明文存储。旧版本没有本轮快照时照常使用已有进度；快照或词表不可恢复时保留已学记录，重新安排本轮。

答题前不出现 AI 讲解入口，避免提前透露答案。查看答案或完成检查后，点“小屿，讲讲这个词”会将当前词义和已有例句交给内置 Qwen 模型；不用复制内容或填写 API。生成中可以继续学其他词，旧回答不会显示在新词下面。讲解是可核查的辅助解释，未自动写成词典事实，且仍可能出错。

完成页给出本轮新词、复习、下一次复习时间及明确的下一步。翻卡自评显示“自评记起次数”，不会被包装成客观正确率；专项巩固有剩余薄弱项时可继续该专项。文章推荐来自已有正文的精确词形匹配，不推断词根、不声称掌握程度，也不伪造文章或命中。

实时听译保留收音、导入音频、按停顿断句、英文修正、重译和听写能力。模型及文件规则折叠在说明中，没有记录时收起无内容可导出的操作区。AI 伴学保持独立侧栏。开启安静模式会收起首页插画；专注学习时不弹出庆祝浮层遮挡答题。

## 验证与当前范围

使用独立测试账号验证了：主按钮位于首屏、计划展开、词书与额度、跨词书重启续学、未完成输入恢复、选择与小循环证据恢复、不重复计分、翻卡自评标注、侧栏和 Esc 暂停、精确文章匹配、390/960/1280 布局。实际调用了内置模型做单词讲解，并验证换词时迟到回答不串题；原生语音识别也已运行验证。

同时回归了小循环与专项巩固、题型提示标记、助记与备份、11 段间隔复习、真实 Windows 系统加密下的记住密码与自动登录、锁定保护、旧记录迁移和关闭保存。相关报告见“验证数据/学习体验重构验证.json”。

当前交付仍是 Windows x64 本机软件。窄屏检查属于界面适配验证，不代表已完成 Android 或 iOS 原生发布。正版内容规模、真人音频覆盖和真实用户的长期学习效果也不能仅凭本轮改造与自动测试认定已经等同商业产品；这部分需要继续通过授权内容建设及真实试用完善。
