## 自动添加与更新

外刊书架上方有“立即更新”，下方展开“订阅与自动更新”即可调整：

- 自动添加与更新默认开启，按账号保存；可随时关闭，关闭后仍能手动更新。
- 检查间隔可选 6、12、24 小时，默认 6 小时。
- NASA、NOAA、NSF 可分别勾选，至少保留一个来源；取消订阅不删除已添加文章。

软件打开且已登录期间自动检查，重新打开会补查到期内容；关闭软件后不会继续运行，也不额外安装 Windows 常驻任务。对已检查且未到周期的来源不重复下载，支持来源服务器的 ETag / Last-Modified 缓存校验。连接失败采用约 15 分钟的重试间隔，避免频繁访问；某个来源失败不妨碍其他来源更新。状态区分别显示来源的最近成功时间或错误信息。

新链接自动加入书架；同一原文链接合并，不反复添加副本。原站改动标题或正文时更新公共缓存，界面提示本轮新增和更新数量。公共滚动缓存最多 600 篇，达到上限时保留发布日期较新的条目；原有离线材料与个人阅读快照另行保留。

## 保留阅读现场与笔记

后台更新不会重新渲染正在阅读的正文，不会替换正在编辑的段落笔记。打开过的新闻保留当前账号的阅读快照，收藏、位置、笔记、生成的译文及生词关联继续按账号加密保存，随账号备份迁移。

原站同一链接有新版时，重新进入文章或正常刷新正文后会提示“这篇文章有新版”。可以继续读原版本，也可主动“查看更新版本”：切换前明确说明位置和旧译文将重新记录，收藏与生词保留，原段落笔记收入“旧版本笔记”，不强行绑定到不同段落。

公共资讯缓存只包含已发布的来源内容，不包含账号信息、笔记、学习记录或 API 密钥；自动检查也不会上传这些个人数据。订阅偏好保存在各自的加密账号内。离线、来源超时或解析失败时保留已有缓存和离线书架，并显示实际结果。
