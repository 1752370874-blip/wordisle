# 3.9.18 · 词屿青春主场

界面改为深海军蓝、荧光青柠、珊瑚橙和薄荷绿的校园运动风格。首页采用主场横幅、跑道线条、运动号码、原创动漫伙伴与清晰的训练卡片；左侧导航、词卡、词库、阅读、查词、听译、伴学和设置保持同一套视觉。启动页也同步更新。

## 更轻松地开始

- “开始今天的训练”进入原有每日练习；到期复习优先，再按剩余新词额度补充，未来才到期的词不会被提前拉来凑数。
- “先热身”默认 5 个词。主动选择“有点累”后提供 3 词热身，不修改每日目标，也不限制继续练习。
- 五种练习方式继续可用：翻卡、四选一、拼写、例句填空和听写；已有听译、术语、AI 伴学及字典功能保留。
- 首页显示的练习次数、到期词和连续天数来自本机真实记录。周历只标出有练习的日子，空白日不标为失败。

## 鼓励和趣味

正确或不熟悉时给出简短、尊重个人节奏的提示。连续记起或当天练习达到 5/10/20 次时，可出现一次短庆祝；没有扣分、虚构积分、排名或付费才能继续的机制。反馈不代表已掌握，也不构成学习效果承诺。

“小屿”是原创视觉伙伴，能提供本地预设鼓励与节奏选择；不会因此自动录音、分析情绪或向 API 发送状态。节奏选择和反馈偏好只随本机设置保存。AI 伴学依然通过原来的独立栏目使用，与这些预设鼓励有清晰区分。

右上角可切换“安静模式”，收起大幅插画和庆祝动画，同时暂停自动发音，仍可主动点击朗读。设置中能单独关闭“学习鼓励”或“轻互动效”；系统的“减少动态效果”偏好也会得到尊重。不新增庆祝声音，关闭安静模式后，单词朗读继续按原来的音源和自动发音设置工作。

## 数据与验证

保留原数据键及体验版用户目录，不清空词库、资料、批注或学习进度。本轮测试也发现并补回了原有学习流程缺失的队列及当前词函数，确保开始训练不只是视觉入口。

已实际检查首页和全部栏目在桌面及 390px 宽度下的布局、插画透明通道、3 词热身、翻卡正误反馈、错词重排、完成总结、四选一正误、拼写/填空/听写、到期与新词配额、键盘操作、关闭反馈、安静模式、重启保存、已有资料保留及系统减少动态效果。听译的长语音和停顿分段继续进行回归验证。
