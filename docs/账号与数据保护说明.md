# 账号与数据保护说明 · 3.9.26-preview

本版新增注册与登录入口，可以设置名字、性别和密码，系统以密码学随机数分配 WI- 加 12 位数字的 ID，并在本机核验不重复；不宣称跨设备全局唯一。无需网络即可注册或登录。性别支持“男、女、其他、不愿透露”，注册时不要求邮箱、手机或真实姓名。

## 使用与恢复

- 注册后保存一次性展示的恢复密钥，再开始学习。可用账号或 ID 登录，账号不区分大小写。默认手动登录；可主动开启记住密码或自动登录，不保存明文密码。
- 右上角账号按钮进入“我的学习空间”，支持修改名字、性别、密码，锁定、退出及导出加密账号备份。锁定与退出先提交最新学习数据，再结束当前会话；Windows 锁屏也会触发保护。
- 密码最低 9 个、最多 128 个字符，不强制混合字符类别。注册、改密、恢复均在本机完成；恢复密钥可以重设密码，并在成功使用后轮换。恢复密钥持有者能够恢复账号，请与账号备份分开保存。
- 换机时导出 .wiaccount 文件，在新设备登录页“导入加密账号备份”输入导出时密码；账号已存在时拒绝覆盖。本机账号本身不是联网注册服务，不包含邮箱找回、云同步或服务器风控。

## 存储与保护范围

账号索引仅保存随机 ID 与账号名 SHA-256 摘要；名字、性别、账号名原文及学习内容存入加密载荷。每个账号有独立的随机 256 位数据密钥。密码通过 scrypt（N=131072，r=8，p=1，独立 32 字节随机盐）派生密钥，只用于包装数据密钥；恢复密钥使用独立随机 256 位秘密。数据、包装密钥和私有附件使用 AES-256-GCM，每次写入生成独立的 12 字节随机 IV，以账号 ID 和用途作认证附加数据。解密验证失败时拒绝读取，不自动清空原记录。

学习记录通过排队写入、临时文件、同步落盘及原子替换保存。学习记录、资料、助记、练习历史、AI 草稿、听译文字与个人资料均加密；个人背景副本和自训练断句模型也按账号加密。公共词库、预置模型、公开新闻缓存及公开训练语料不属于个人账号数据。原音不写入账号文件，API 密钥不加入学习存储或账号备份。

学习窗口使用内存会话，账号数据不再写入浏览器 localStorage。主进程核验 IPC 请求来源、主窗口、主框架、登录状态与会话代次；登录页和未登录状态不能调用学习、AI、录音或私有存储接口。切换账号销毁旧页面，清理内存会话存储、停止收音、推理与训练，拒绝旧会话的延迟结果。

首次注册可选择迁移旧版数据：先读取并验证旧记录，将学习记录、应用管理的背景副本及断句模型加密写入新账号，成功后才清理旧版 localStorage 和已迁入的应用副本；迁移失败保留旧数据。取消迁移会保留原来的旧记录。旧备份、原图片、其他应用或其他数据目录内的文件不会自动删除或加密；普通删除也不等于磁盘安全擦除。

## 记住密码与自动登录

仅在用户勾选且密码验证成功后，保存最近一个账号的系统加密凭据。使用 Electron safeStorage 的系统加密，在 Windows 上基于 DPAPI；先执行加密与解密自检，失败时禁用保存选项。真实的已保存密码只在主进程内用于重新验证账号，不回传页面、不存 localStorage、不加入学习 JSON 或加密账号备份。取消记住、切换账号、清除登录信息、修改或找回密码后删除旧凭据。锁定状态持久化，锁屏或手动锁定后不能用记住的凭据或自动登录绕过；正常关闭保持用户选择。首次保存后应正常退出，以便系统加密服务完成配置写入。

自动登录信任当前 Windows 用户会话；它不能防止拥有同一 Windows 用户权限的软件或正在使用已解锁电脑的人进入应用。系统保护失效或凭据无法验证时会回到手动登录。

## 适用边界

这是保护未解锁的本机数据与备份的应用层措施，不能承诺绝对防泄露。已经解锁时，能控制当前电脑的人仍可看到屏幕内容；系统管理员、恶意软件或被接管的运行环境超出本版保护范围。主动导出的学习 JSON、听译文本、截图及复制到剪贴板的内容不受账号文件加密保护。选择 API 服务时，提交给该服务的内容依既有功能发送，账号系统不会代替该服务的数据管理政策。

登录失败限制在本次进程内：同一登录输入连续失败 5 次后等待约 30 秒，退出重启会重置；不能视为抵御复制账号文件后的离线破解。密码长度、scrypt 和加密密钥才是文件保护的基础。忘记密码且没有恢复密钥时无法找回；请保留自己的加密备份与恢复密钥。
