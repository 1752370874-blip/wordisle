# 词屿 3.9.3 Enhanced 使用说明

> 本文同时作为 GitHub Release v3.9.3 的发布说明。

## 这是什么

词屿（Word Isle）是一个离线可用的英语学习桌面应用。3.9.3 Enhanced 在 3.9.2 的基础上新增「文章词汇地图」，其余功能（词库、学习、阅读、查词、统计、设置）与原版一致。

- 安装版：下载 `WordIsle-Enhanced-Setup-3.9.3.exe`（约 127 MB），双击安装。
- 免安装版（本仓库之外的 `词屿修复版` 文件夹）：双击其中的 `WordIsle.exe`。请保留整个文件夹，程序需要同目录下的 `resources` 和其他文件。

## 新增：文章词汇地图

1. 打开应用，点侧栏「文章词汇地图」。
2. 把英文文章粘贴到文本框（单次最多 20,000 字符），点「生成词汇地图」。
3. 结果：
   - **绿色**：该词形在本机有练习记录；
   - **橙色**：该词形没有练习记录；
   - 顶部给出「练习记录覆盖率」、总词次，以及没有记录的不同词形数量。
4. 点「清空」可以清除当前文章。

### 怎么看这个结果

- 统计按**原词形精确匹配**，不推断复数、时态等词形变化，所以 `study` 与 `studied` 算两个不同的词。
- 「练习过」不等于「已经认识」，「没有记录」也不等于「不认识」——它只反映本机的练习数据，不能替代真实的词汇量测试。
- 想提高覆盖率，就把橙色词收进生词本或用「查词生词」词库练习。

### 隐私

粘贴的文章只在程序内存中用于分析，**关闭后不会保存**，不写入数据文件、不参与备份同步、不发网络请求。

## 升级须知

- 新版本沿用原程序的数据路径设计，**可能读取和修改原有的学习数据**。如果原程序还能打开，请先在「设置」中导出备份，再安装新版本。
- 本次验证使用独立测试数据，**未验证**您原有数据的迁移情况。
- 此版本为独立文件夹/独立安装包，不会自动修复或替换桌面原有快捷方式。
- 原安装包的签名证书未被系统信任；修改后的程序也**没有重新进行可信代码签名**。Windows SmartScreen 可能提示「未知发布者」：点「更多信息 → 仍要运行」。

## 校验

安装包由 GitHub Releases 分发，可在 Release 页面查看文件大小。下载后如需核对，可对自己的副本计算哈希：

```powershell
Get-FileHash .\WordIsle-Enhanced-Setup-3.9.3.exe -Algorithm SHA256
```

与 Release 说明中列出的 SHA256 比对一致即可。
