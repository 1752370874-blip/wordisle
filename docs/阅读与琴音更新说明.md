# 词屿 3.9.29：把阅读和积累连起来

## 更柔和的答题琴音

答对播放轻快上扬的四音旋律，答错播放温和收尾的三音旋律。每段约 0.7 秒，使用叠加泛音、轻微失谐、错落的触键力度和渐弱包络，减少单一提示音的生硬感。这是词屿原创的本机合成琴音，不是真人语音或其他软件的音频素材。

四选一、引导体验题和阅读理解题使用相同的反馈；安静模式静音，设置中可调整提示音音量、关闭和分别试听。连续点击不会叠加或重复播放；单词发音仍使用原有独立设置。

## 从书架到同页精读

左侧“外刊阅读”进入新的英文书架。内置原有 52 篇原创外刊风格文章与经典节选，共 108 道理解题；保留来源标识，不将原创材料当作真实外刊转载。支持标题和正文搜索、话题筛选、“轻松读 / 进阶读 / 挑战读”参考难度，以及发现、收藏、已读、个人剪藏分类。难度按材料标签归组，不是个人英语能力测评；预计时间按每分钟约 140 词估算。

书架提供继续上次未读完的文章；进入正文后恢复上次阅读段落。原文优先，点词即可查义；需要时再展开已有译文，或启用双语对照。没有参考译文的段落可调用内置 Hy-MT2 翻译，Qwen 负责“小屿讲解”。两者均在本机运行。AI 译文和讲解标明来源，只参考所选段落，需结合原文核对；讲解结果保留在本次窗口，段落译文按账号保存。

每段可直接听读和写笔记，笔记自动保存。朗读沿用设置中的在线或系统英语合成语音，并提供 0.75 / 1 / 1.25 倍速；不是已配齐的真人录音。阅读设置内可调整字号和暖纸、清爽、夜读背景；常用操作留在正文附近，设置按需展开。

点词收藏及本篇重点词可加入“阅读生词”，附带本篇语境，不自动更换首页词书计划。展开本篇重点词后可直接复习收藏的生词：少于四词采用翻卡，足够时采用四选一。阅读理解题保留已答选项和解释，可重做；练习正确率只反映当前题目，不代表整体阅读水平。

## 阅读记录与自己的材料

读完后主动点“我读完了”，阅读日历记录当天完成情况；同一文章一天只计一篇，次日重读可再次记录。每日小目标可选 1—3 篇，不发出强制提醒。仅打开、滚动或播放文章不会自动认定已经读懂。

“添加我的文章”可粘贴有权使用的英文正文、填写标题、原文链接及参考难度。最多 30 篇个人剪藏，每篇最多 30000 字符、80 段，单段最多 5000 字符；空行分段。正文和链接不会由此自动上传或抓取。剪藏可在文章的阅读设置内移除，移除前会明确确认。

NASA 新闻按需联网更新，保留抓取时间、发布日期与原文链接，并明确展示为节选。读过的新闻节选随账号保存，后续更新不会把已有笔记绑定到不同内容。其他媒体通过官方入口用系统浏览器打开，具体全文访问仍由原站提供。离线可继续阅读内置材料、个人剪藏与已保存的新闻节选。

阅读位置、收藏、笔记、译文、题目答案、日历和剪藏均进入当前账号的加密学习空间，并随加密账号备份迁移；主动导出的学习 JSON 同样包含这些内容，属于明文文件。清空学习进度会清除阅读位置、已读状态、题目答案和日历，保留剪藏、收藏、笔记、生词关联与已生成译文。文章内容更新时，旧段落笔记保留在“旧版本笔记”内，避免错误附到新段落。
