# 词屿：实时听译与 AI 伴学的赛题对标

依据用户提供的“AI 赋能学习生产力——面向移动终端的场景创新”赛题内容，当前版本聚焦英文听讲与音频理解：从声音获取英文，再利用中文辅助理解，并把英文交给伴学工具继续提问。赛题方向为启发，不应声称必须覆盖全部方向。

## 当前完整流程

1. 用户主动选择麦克风并开始收音，或导入已有英语音频。
2. 本地 Whisper tiny.en int8 将音频分段识别为英语，随后本地 Hy-MT2 1.8B 或用户选择的 HTTPS API 译成中文。
3. 中英对照保留来源名称与音频内时间范围。用户停止后可以修改识别英文、重新翻译、修订中文。
4. 中英全文可导出 TXT；识别英文可保存为伴学资料，继续提问、解释难句或出题自测。
5. 伴学显示本次使用的原文片段，最近问答及批注随资料保存并纳入 JSON 备份。

原“资料学习”独立页面、全文翻译 / 提词练习入口和局域网手机录入已移除。已有资料、问答与词库保留。普通词库复习及查词功能继续使用原有数据。

## AI 与自研部分

语音模型为现有 Whisper tiny.en，由 sherpa-onnx 作者提供 ONNX int8 转换，运行于 sherpa-onnx-node 2.0.1 / ONNX Runtime 1.28.2。中文翻译已改用专用 Hy-MT2 1.8B Q4_K_M；伴学与听力解析使用 Qwen3 1.7B Q4_K_M，运行于 node-llama-cpp 3.22.3。这些模型与 Silero VAD 均只集成推理。

团队实现音频采集、外置麦克风选择、音频解码与重采样、按停顿和长度分段、处理队列、背压提示、权限与设备状态处理、中英修订、导出和伴学接续。3.9.15 新增自行训练的轻量英文句界分类器，结合上下文、词形与大小写判断句界；训练源码、公开语料、许可证和独立测试报告随包提供。没有重新训练语音识别或语言大模型。数字字符串核对和听写词级匹配属于规则功能。

麦克风默认采用 Silero 神经网络检测人声，约 0.8 秒停顿结束片段；3.9.17 已取消按固定时长强制截句，等待实际停顿或结束后提交；长段在识别器内部计算后合并，因此存在延迟。可关闭智能断句回到能量阈值方案。Whisper 的本地识别不向外部发送录音；选择 API 翻译或听力解析时，识别出的英文在用户确认后发送给服务商。

## 2026-11-07 验证记录

- 使用转换模型仓库提供的真实英语 WAV 样本完成实际语音识别与中文翻译；英文输出包含参考转录的关键短语。样本约 6.6 秒，本机一次语音识别与翻译总耗时约 3.4 秒，不能据此承诺其他设备或音频的速度与准确率。
- Node 后端检查了静音不生成英文、无效采样率及 NaN 采样被拒绝。测试未使用 API 密钥，本地测试进程的网络请求函数被禁用；模型从本地文件读取。
- Electron 使用 Chromium 的模拟音频输入，把同一英语 WAV 送入真实 getUserMedia → AudioWorklet 采集流程，完成英文识别与中文翻译。测试没有录取用户周围声音。
- 桌面自动化通过音频文件导入、修订英文后重译、实际 TXT 下载、停止与导航释放麦克风、权限拒绝提示、空 API 配置校验、伴学保存及重启恢复、旧资料保留、资料学习页面移除和 390px 窄屏布局。
- 模型和 Windows 原生组件按发布哈希校验后打包。完整许可证保留在模型和运行组件目录。
- 3.9.14 将听译中的内置翻译选项明确命名为“内置模型 · Qwen3 1.7B（离线）”；译文显示所用模型，手动修订会标注。桌面测试验证无密钥下实际调用内置模型，保留 API 选项。
- 3.9.15 实际训练英文句界分类器：训练 1385 句、验证 292 句、独立测试 1692 句。软件采用保守阈值，文本句界测试精确率 80.9%、召回率 41.1%、F1 54.5%。这些不是 ASR 准确率或真实课堂指标。断网后从随包校验缓存重新训练，权重与基线一致。
- 真实 Silero VAD 对英语样本输出语音片段，对 8 秒恒定幅度噪声不输出片段。拼接约 79 秒英语素材得到 6 段，最长约 13.7 秒，未超过识别上限。这只是受控样本，不能替代教室噪声测试。
- 新增听力练习完成实际原音播放、变速、隐藏字幕、词级差异、提示标记、内置 Qwen 解析、记录持久化、训练报告下载，以及 390px 窄屏布局检查。
- 公共语料训练与自有 TXT 训练均测试了模型实际训练、启用、重载及恢复；不足语料拒绝与取消训练会保留当前模型。对测试集的 316 个文档移除句末标点后运行断句，词汇序列保持一致；缩写和小数保护通过检查。尚未开展真实学生学习效果对照实验。

## 2026-11-08 翻译升级验证

3.9.16 实际训练 10,876 句英文断句语料；新旧模型在相同的 1,683 句测试数据上，保守阈值精确率由 80.9% 至 89.4%，召回率由 40.9% 至 44.6%，F1 由 54.3% 至 59.5%。这些是文本句界分类指标。

新增 23,754 条训练例句的 IDF 检索模型，按英语组分区，2,998 条验证及 3,023 条测试不进入运行时例句库，保留逐句贡献者。没有微调 Hy-MT2 或 Qwen。

实际完成 24 组团队编写的翻译开发用例、同轮上下文与自定义术语、一次自动复核、API 复核失败保留首译、规则提示、偏好持久化及桌面与窄屏操作验证。24 例是开发回归，不能宣称权威榜单、旗舰水平或翻译准确率。原文照抄和背景串入等已观察到的问题有改善，仍存在措辞生硬和原文外推测风险。详见《翻译升级验证.md》。

## 3.9.17 按实际停顿分段

移除了 12/14 秒的时长截断。Silero 逐帧检测人声与持续停顿，短换气尽量合并；长连续讲话可跨过此前的时长边界。文件导入与麦克风输入统一按神经网络采样帧处理，避免大批次吞掉停顿。识别器内部的长音频计算窗口不作为界面中的音频句界。

受控真实语音测试中，约 23.5 秒的连续语音只形成一个片段，在末尾停顿后提交；插入 1.2 秒及 2 秒停顿时形成三段。100ms 和 1s 两种输入批次产生相同音频边界。约 79 秒的原始拼接样本包含可检测停顿，逐帧处理后形成 12 段；它不是无停顿样本。完成长段识别合并、原音回放与桌面/窄屏界面测试。详见《停顿断句验证.md》。

## 参赛前仍需验证

当前为 Windows 桌面系统，未提供手机端语音模型推理、账号同步或多设备接续，不能宣称已完成移动终端落地。真实 USB / 蓝牙麦克风、不同电脑、教室噪声、专业授课、口音、多人重叠讲话和长时间连续录音仍需实际试用。当前版本不直接采集电脑内部播放音频。

小模型可能误译或产生不可靠回答；语音模型可能在噪声、音乐或非英语输入下误识别。应采集经同意的真实授课样本，评估英文词错误率、关键术语与数字错误率、句末到译文出现的延迟、人工修订时间，以及学生能否独立解释内容。用户访谈与学习效果比较尚未开展，不应宣称已提高学习成绩或完全满足竞赛评审要求。
