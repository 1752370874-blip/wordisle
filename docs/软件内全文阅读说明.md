# 词屿 3.9.35：软件内直接阅读全文

所有栏目统一在词屿内阅读。已有完整正文采用原精读器；未缓存正文的文章点击“阅读全文”，打开词屿自己的官方原文阅读窗口，不再跳出到系统浏览器。来源文章的页面内容、图片及必要的原站交互由原发布方直接呈现，不代理转载全文。

在线窗口的工具栏提供返回书架、前后导航、重新加载、原版页面和 75%—175% 文字缩放；关闭窗口即可继续原书架。NPR 默认用官方纯文字版，ScienceDaily 等使用原版页面。已缓存的 150 篇正文、笔记、生词及阅读进度继续保留。

在线全文与已下载正文是两种状态。在线原文需要网络，受原站实际访问和订阅条件影响；页面失败会显示重试，不以 RSS 简介或摘要冒充全文。允许提取的来源可另选“保存为精读”，成功后支持已有的离线精读功能。

远端页面采用独立的 WebContentsView 和临时会话，开启 sandbox、contextIsolation、webSecurity，禁用 Node、预加载应用桥、弹出新窗口和下载。其页面不能调用词屿账号或本地文件接口；只允许当前官方来源内的 HTTPS 顶层导航，不修改证书校验。锁定或退出学习账号会销毁原文阅读窗口，并清理其临时会话。

请完整退出当前旧窗口，再打开本目录 WordIsle.exe 加载新版。
