# 词屿 3.9.21：界面与交互优化

本次参考系统交互中连续、明确、轻量的反馈方式，沿用词屿自己的青春配色和原创插画。参考了 [Apple 的动效设计入口](https://developer.apple.com/design/human-interface-guidelines/motion) 以及 [减少动态评估指导](https://developer.apple.com/help/app-store-connect/manage-app-accessibility/reduced-motion-evaluation-criteria/) 中尊重动态偏好、提供替代反馈的原则。当前作品仍是 Windows / Electron 软件，不声称使用 Apple 原生控件或获得完全一致的系统体验。

## 已落地的交互

- 侧栏使用单个滑动指示层，切换栏目时连续移动；分段选择条使用轻浮的选中块。选项文字始终保持可辨对比度，指示层不接收点击、不进入键盘顺序。
- 按钮、选项、查词结果和快捷入口提供直接的按压轻缩及松开回弹；触控不依赖悬停。圆角与阴影更加统一，保留原有配色和信息结构。
- 新页面用短距离过渡衔接；翻卡显示释义、答题反馈、下一个词和学习进度条各有短促反馈。主要受控动画约 170—280 毫秒，可打断，不延迟写入数据，不锁定点击。
- 词书复习规则、个人助记、校园联想等折叠内容可轻量展开与收起。大范围内容不强行动画，快速反复点击以最后一次意图为准。
- 刷新前后保留输入焦点、光标、未提交答案、展开状态和滚动位置；如果新的界面明确改变了字段值或禁用状态，以新状态为准。
- 内容完全相同时保留已有节点，减少输入框和面板反复重建。返回列表和阅读页面恢复位置；换词回到练习起点，选中新词书后直接露出首页计划。
- 查词和词书搜索在中文输入法组合过程中暂缓重绘，选字结束后更新结果。异步状态刷新不会在组合输入中途拆掉输入框。

## 流畅性的实现改进

移除了青春界面仍在叠加执行的旧页面/区块入场动画，改为每次只为发生变化的层添加短动画。受控动画只在交互、界面变化或尺寸变化时启动，没有持续运行的逐帧主循环；切换操作和偏好变更会清理失效动画。

首页的薄弱词不再每次扫描 74,278 条词书收录，而是复用词汇索引、按已有学习记录取词。词书进度按数据版本与最近到期时间缓存，作答后立即失效，恢复数据和修改词书内容时重新计算；系统时间回退也会重新计算。同一次渲染共享活动词池，减少重复构造。

没有改动词书范围、每日 300 个新词上限、复习间隔、模型权重或学习记录含义。原有资料、助记和偏好继续使用。

## 动态偏好与键盘

继续使用“设置 → 轻互动效”，不增加必填设置。关闭该选项、开启安静模式或系统减少动态时，停止受控位移与回弹；当前尚未完成的展开动作直接落实到目标状态，避免面板停在半开的位置。功能和焦点仍可正常使用。指示层只作视觉反馈；按钮、输入框和 summary 保留原生键盘操作与可见焦点。

## 验证结果与范围

在独立测试数据目录启动实际桌面程序完成验证，未修改用户真实学习记录：

1. 快速连续切换栏目和筛选条件，检查选择立即生效、指示层数量和最终对齐，无残留活动动画。
2. 使用真实指针按下/松开事件检查反馈及按钮激活，确认不需要等过渡结束才执行操作。
3. 检查原地刷新不重建相同内容；改变内容时仍保留展开状态、summary 焦点、未提交答案、光标及滚动位置。
4. 检查中文组合输入、异步刷新与选字结束的结果更新；检查往返词书列表、选书返回首页及页面位置恢复。
5. 检查快速开合面板，以及中途启用安静模式、关闭动效、系统减少动态后的完成状态和动画清理。
6. 检查 390 / 1280 像素布局；回归词书每日计划、五词小循环、分项补练、其他题型与旧资料保存。
7. 使用实际 WAV 和模拟麦克风回归实时听译、修订重译、导出、导航释放麦克风、权限拒绝及伴学保存恢复。

同一台机器、相同独立配置下，用 `performance.now()` 测量每个页面连续八次同步渲染并触发布局读取，得到：

| 页面 | 优化前中位值 | 优化后中位值 |
| --- | ---: | ---: |
| 首页 | 25.25 ms | 2.85 ms |
| 词书页 | 21.85 ms | 1.80 ms |
| 查词页 | 1.15 ms | 1.10 ms |
| 设置页 | 3.20 ms | 1.35 ms |

这是重复刷新场景中脚本与布局的有限测量，不是屏幕帧率或所有设备的流畅度保证。词书页首次读取及布局的最大单次耗时仍约 55 ms，模型推理、首次资源载入、设备与窗口状态也会影响体验。原始测量记录随包保留在《验证数据/交互性能对比.json》。
