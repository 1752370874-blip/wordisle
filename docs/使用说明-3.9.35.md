# 词屿 3.9.35：软件内直接阅读全文

完整解压后双击 `WordIsle.exe`。请保留整个文件夹；本地模型和运行组件位于 resources 中。建议 Windows x64、8 GB 及以上内存（16 GB 更稳），下载和解压合计预留约 7 GB 磁盘空间，无需独立显卡。

## 不离开软件阅读全文

ScienceDaily、NPR、Smithsonian、Science News Explores 等文章现在点击“阅读全文”即可在词屿自己的阅读窗口中显示官方完整页面，不再启动外部浏览器。窗口支持返回书架、后退、前进、重新加载、原版页面和文字缩放。NPR 优先采用官方纯文字版，其他来源使用官方文章页面。

已取得完整正文的文章继续在精读器中使用查词、笔记、翻译和离线阅读；尚未缓存的文章默认在线阅读全文，支持提取的来源另有“保存为精读”。原站在线阅读需要联网，网站不可用或需要订阅时会显示实际结果，不能保证全部文章已离线下载。

## 文章来源栏目修复

修复 Windows 软件在“全文阅读”选中 NPR 后显示 0 篇的问题。默认书架改为“全部文章”，另有“站内全文”“原站全文”标签；选择具体来源时自动退出不匹配标签并重置难度和话题。NPR 综合、世界、图书、教育各内置 10 个真实原文入口；16 个来源频道均有文章条目。

订阅面板明确显示栏目文章数、站内全文数和原站入口数，并可直接“查看 N 篇”。RSS 检查成功只说明文章索引更新，不代表取得正文。NPR 链接打开其官方纯文字全文页；150 篇已内置全文和个人笔记保留。完整退出旧窗口后，重新打开本目录 WordIsle.exe 即可加载修复。

## 朗读显示修复

修复朗读高亮竖线遮住段首单词的问题。高亮边线与文字之间固定留白，播放、暂停及拖动进度时不再改变段落宽度或文字位置。暖纸、清爽、夜读背景及窄窗口均适用。完整退出旧窗口后重新打开本目录 WordIsle.exe 生效。

## 统一的新图标

Windows 程序文件、窗口、任务栏、启动页、登录页与侧栏统一采用新的书页、小岛弧线和星光图标。完整退出旧窗口后再打开新版即可看到。图标源文件、规格与验证说明见《图标更新说明.md》。

## 直接阅读全文

左侧打开“外刊阅读 → 全文阅读”，点击文章就能读英文正文。新版内置 150 篇经过完整性校验的官方来源全文，保留 52 篇词屿原创与经典材料；经典节选仍明确标注为节选。另有 14 篇暂未取得全文的文章入口，打开后可重试或转原站。旧版 RSS 摘要不再出现在正文阅读器中。

新文章从原网页正文区域提取文字，逐项保留到最后一段，不再只截取前 8 段。获取成功后可离线继续，支持点词查义、段落笔记、收藏、阅读位置、内置 AI 翻译与讲解、语境生词复习。已有笔记保留，正文更新时旧笔记收进“旧版本笔记”。

NASA、NOAA、NSF、MIT News 配置为正文来源；本次真实抓取成功 150 篇，失败的 14 篇没有用摘要补齐。NPR、Smithsonian、ScienceDaily、Science News Explores 等继续保留订阅与“原站文章”入口，由浏览器在原站阅读全文，不将摘要冒充全文。原站付费、403 或结构无法确认时明确显示原因和重试入口。

订阅仍支持 6 / 12 / 24 小时检查，默认推荐四个正文来源；自选来源、关闭自动更新的偏好保留。检查新条目后优先预取少量正文，其他文章点击时再获取，最多保留 1500 条公共缓存。软件打开并登录期间自动检查，关闭自动更新会取消当前请求。

正文为英文文字，包括识别到的标题、段落、列表、引语与表格；不下载原站图片或执行网页脚本。每篇完整阅读容量为 400 段、20 万字符；超出时转原站，绝不悄悄截断。MIT News 保留标题、副标题、作者、原文链接与要求的转载署名。详见《全文阅读说明.md》。

## 阅读与柔和琴音

阅读设置可调整字号、背景和朗读速度，支持双语对照、每日 1—3 篇小目标及主动记录“我读完了”。原创材料的理解题、个人剪藏与逐段本地 AI 功能继续提供，不给外部文章伪造参考译文或配套试题。

答题提示为约 0.7 秒的柔和琴音，答对轻快上扬，答错温和收尾；音量、开关和安静模式仍有效。

## 新手引导与答题音效

新账号进入学习空间后会显示四步引导，帮助选择词书、设置每日目标、体验答题和了解常用工具。每一步都能跳过，欢迎页可直接选择“我很熟悉，直接进入”；设置中可重新查看。体验题不计入学习进度；完成或跳过后不再自动出现，旧账号升级不会强制引导。

四选一答对、答错会播放不同的轻提示音。在“设置 → 音效与使用帮助”中可开关、调整音量及试听，安静模式统一静音。详见《新手引导与音效说明.md》。

## 一条更顺畅的学习流程

首页点“开始学习”即可按当前词书和方式开练，每组最多 10 词，复习优先；有未完成练习时显示“继续本轮学习”。词书和每日 1—300 词目标在“调整计划”中设置，专项练习和其他模式按需选择。

学习页默认专注展示当前题目；可显示导航，也可用“暂存并离开”或 Esc 暂停，重启并登录后仍可继续。拼写草稿、选择题和小循环阶段会一并保留，已提交的学习记录不重复计分。

看过答案后可让“小屿讲讲这个词”，直接用本机模型解释词义与已有例句。完成页给出下一组、休息或专项巩固入口，并在已有文章里寻找刚学词形的实际出现。细节、对照依据与验证范围见《学习体验重构说明.md》。

## 更轻松的登录

登录页借鉴常见即时通讯软件的头像、账号密码输入框和并排选项布局，保留词屿自己的图标与配色。密码框下方可勾选“记住密码”和“自动登录”，首次使用默认均关闭。

只选“记住密码”，正常关闭后再次打开会保留账号，并以圆点提示已记住；点登录即可进入。勾选“自动登录”时会同时开启记住密码，正常关闭再启动会自动进入，进入前提供“取消自动登录”。取消记住密码会同时关闭自动登录并立即清除已保存的凭据。

“退出账号”会关闭自动登录，保留已选择的记住密码供下次主动点击；“锁定”及 Windows 锁屏后要求手动输入密码，即使重启也不会自动绕过。手动输入正确密码并保持自动登录勾选，可恢复后续自动进入。修改或找回密码后清除旧记住信息；登录页“切换账号 / 清除密码”及设置中的“清除已记住的密码”也可随时清除。

保存的凭据由 Windows 用户加密机制保护，不写入明文文件，不加入账号备份，也不把已保存的真实密码回传页面。请在自己的电脑上开启；同一 Windows 用户下的其他程序仍属于系统安全边界，不能将自动登录当作防止他人使用已解锁电脑的措施。系统保护不可用或保存信息失效时回退手动登录。详细说明见《登录偏好说明.md》。

## 先注册自己的学习空间

打开后先进入注册或登录页面。首次使用填写账号、自己的名字、性别和密码，系统随机生成 WI- 开头的 12 位数字 ID；性别可选“不愿透露”。账号为 4—32 位字母、数字或下划线，不区分大小写；密码为 9—128 个字符，可以用容易记住的中文短句。之后可用账号或 ID 和密码登录，无需邮箱或网络。

这是本机账号，注册信息和学习记录不上传到账号服务器，也不会自动跨设备同步。不同账号使用各自的加密学习空间；默认需手动登录；可在登录页主动选择记住密码或自动登录。右上角账号按钮可修改名字、性别和密码，也可一键锁定或退出；Windows 锁屏时会锁定学习空间。原有学习操作无需反复输入密码。

注册后请保存恢复密钥，忘记密码时点登录页“忘记密码”重设；使用后会生成新恢复密钥，旧密钥失效。密码和恢复密钥均遗失时，程序无法解密已有记录。换机前，在“设置 → 我的学习空间”导出 .wiaccount 加密账号备份，到另一台电脑的登录页导入，并输入导出时的密码。本机已有同名账号时不覆盖现有记录；旧备份仍需旧密码。

首次注册可勾选将旧版本机记录迁入此账号（默认勾选）。迁移成功后会清理旧版应用存储及已迁入的应用内背景、断句模型副本，原始图片不受影响。未勾选时旧记录仍会留在原位置，不能视为已受新账号保护。历史导出文件也不会被自动修改。请确认在正确的本机用户环境中迁移。

学习进度、助记、资料、听力练习、个人资料以及保存的背景副本、自训练断句模型均按账号加密保存。AI 伴学草稿和最近听译文字可在重新登录后恢复，原音和 API 密钥仅保留在会话内。设置中的“导出学习 JSON（明文）”供主动交换学习记录，其文件未加密；日常备份优先使用加密账号备份。

详细保护范围、恢复方式及验证记录见《账号与数据保护说明.md》。

## 更自然的交互

保留词屿的青春配色和原创伙伴，统一了柔和圆角、轻阴影与控件反馈。侧栏和分段选择条以短促滑动衔接，按钮按下轻缩、松开回弹；切换页面、显示释义和切换下一个词也有轻量过渡，点击会立即执行，不需要等待动画结束。

重复刷新时尽量保留页面节点、输入焦点、光标、展开状态与滚动位置；查词和选书支持中文输入法组合输入，避免拼音尚未选字时打断。返回词书列表或阅读页面时恢复原来的位置，选中一本新书后回到首页计划顶部。词书进度缓存会在作答、数据替换或到期时更新，减少重复扫描整套词库。

已有设置中的“轻互动效”控制界面动画，右上角“安静模式”也会停止动效；系统的“减少动态/动画效果”偏好会自动生效。快速点击时，动画可以被下一次操作打断；关闭动效时未完成的展开动作直接落实到目标状态。详细验证与性能范围见《流畅交互说明.md》。

## 选词书、定词量、开始背词

首页的“调整计划”可选择词书并设置每天 1—300 个新词；支持手动填写，也可选 20 / 50 / 100 / 300 快捷值。主按钮每组最多安排 10 词；“到期复习”仅练已到时间的词。每日新词额度由所有词书共同使用，换书不会重置；复习另计。其他入口的普通队列每轮上限仍为 60 词，目标可以分组完成。

词书广场内置 42 本，覆盖小学、初中、高中、大学、雅思、托福、GRE 及通用词汇，支持按阶段筛选与名称搜索。小学有 843 个编选基础词，提供综合书及 14 个主题分册；初高中、大学和出国考试增加标签总表或常用/进阶分册。不同书会重叠，总计 74,278 条词书收录、16,521 个去重词形，不应把收录条数当作不重复词汇量。开源词典标签与词屿编选内容不等同于某出版社原书、具体教材版本或最新官方考试大纲全量词表。

同一词形的学习进度跨书衔接；已有多份旧记录时优先采用最近一次学习记录，旧条目保留，已有助记也会保留。升级前已选择的词书范围继续使用，不会因为新加词书就自动混入小学词或其他考试词。未设置过的新用户默认从四级核心、每天 20 词开始。

间隔复习遵循前密后疏的规律，基础间隔依次为 5 分钟、30 分钟、12 小时、1 天、2 天、4 天、7 天、15 天、30 天、60 天、90 天。这些是每一次复习之间的间隔，不是从第一天累计的日期；是词屿的规则型实现，不是艾宾浩斯唯一规定的周期，也不是百词斩的私有算法。到期且答对才进入下一阶段；提前练习既不跳级，也不推迟当前的到期时间。模糊约 10 分钟后再见并退一阶段，忘记约 5 分钟后再见并重新巩固。

首页显示当前书的进度、到期词和下次复习时间。展开“艾宾浩斯复习安排”可查看规则与未来七天已安排的复习；到期词在打开的软件内刷新显示，关闭软件期间不会发送系统通知。旧记录已有的未来到期时间保留，到期作答后逐步按新规则安排。个人记忆效果存在差异，不据此保证掌握或考试成绩。更多来源和验证信息见《词书与复习说明.md》。

## 五词小循环与薄弱项补练

首页点击“开始 5 词闯关”，按“认识它 → 换个方式想起 → 独立写出来”完成一小组。选词优先到期复习，再按当天剩余新词目标补入；不足五词时按实际词数出题。选择“有点累”后缩为三词，不修改每日目标。闯关包含英文选义、中文选词、听音选义、无首字母提示的拼写或听写，不依赖同一例句反复猜答案。

答错或使用提示的词最多额外出现一次，完成后列出逐词回顾。翻卡是自评，不计入客观正确次数；完成一个词的最后一轮检查才更新一次复习日程，中途退出时，尚未完成的词不会被判为通过。先错后对仍保留短期复习；未到期的重复答对不会把间隔不断累乘。它是可解释的规则编排，尚无长期学习效果实验。

“错词本”上方按词义、拼写、听辨显示待补练，点击“针对性补练”最多练十词；同一分项连续两次不看提示答对才退出待补练。旧记录缺少题型时先按词义补练，历史错词保留在下方；自定义词库与内置词库重名的学习记录也可查看。听辨来自题目作答，不做口语发音评分。

翻卡后或客观题答完后，可以展开“校园联想”或写“我的助记”。本次内置 32 个原创联想例句，并非全词库逐词配图；未覆盖的词仍显示自身词库例句。个人助记限 240 字，自动存入本机，随 JSON 学习备份迁移。客观题作答前隐藏联想、助记与完整例句；提示后的正确答案标为“需巩固”。听音题沿用设置中的发音来源；断网时可使用已安装的英语系统语音。安静模式下点击按钮手动播放。

对比依据与功能取舍详见《百词斩对比与借鉴.md》。

## 实时英语听译

左侧打开“实时听译”。“中文翻译方式”可选择“内置翻译模型 · Hy-MT2 1.8B（离线）”或“AI API · 自选服务”，再点击“开始听译”或导入音频。内置翻译调用专用 Hy-MT2 模型；AI 伴学与听力学习解析继续使用 Qwen3，无需账号、网络、密钥或额外安装服务；新用户默认选择内置模型，已有选择会保留。每段中文旁标明使用的模型，手动修改中文后会注明已修订。

USB、蓝牙等外置麦克风需先接入 Windows，再点击“刷新麦克风”并选择设备。开始前不会录音；收音时显示音量条。点击“停止”或离开栏目会关闭麦克风，已采集的片段继续处理。设备被拔出、权限被拒绝或处理积压时会显示提示。Windows 拒绝访问时，请检查“隐私和安全性 → 麦克风 → 允许桌面应用访问”。

默认开启“智能断句”：Silero VAD 神经网络逐帧判断人声，结合约 0.75 秒的非人声持续时间决定是否结束片段；英文识别稿再整理标点与分行。短暂停顿或换气尽量留在同一段，不按 12 秒、14 秒等固定间隔截句。连续讲话会等待实际停顿后提交，停止或文件结束则提交尚未完成的末段；较长片段处理时间也会增加。可关闭智能断句，回到能量阈值分段。当前版本不直接采集电脑内部播放声音；可以导入原音频文件，或使用麦克风收音。请尽量靠近麦克风，减少音乐、回声和多人同时说话。

“导入音频”支持浏览器能够解码的 WAV、MP3、M4A、OGG、WebM、FLAC 等文件，单个文件限 50 MB、30 分钟。不支持的编码会提示转换为 WAV / MP3。文件按段处理；点击停止后完成当前段，停止后续处理。识别器对长片段在内部选择低能量位置分块，保留重叠并合并识别结果；这些计算块不增加界面记录，也不被当成声音中的句末。单轮麦克风最长 30 分钟、当前窗口最多 400 段，可导出并清空后继续。

停止处理后，可直接修改识别英文和中文。英文识别有误时，改正后点击“按修订英文重译”。数字遗漏提示仅比较数字字符串，不能验证全部内容。小模型可能误识别人名、专有名词、口音和噪声，也可能误译，请对照音频核查。

“导出中英 TXT”保存时间范围、来源、英文及中文全文。“将英文保存到伴学”会将识别英文保存为一份新资料，随后进入 AI 伴学。当前听译记录只保留在本次窗口内，关闭前请导出；原始音频不会自动保存到学习资料库。

## 翻译增强与偏好

默认自动参考同一轮听译前两段已完成的中英文，匹配学术术语及高相似度英汉例句，帮助理解指代和保持译法一致。展开“翻译偏好”，可选“学术清晰 / 自然通顺”，以及自己的术语（每行 English = 中文）。只匹配当前原文实际出现的术语，偏好随 JSON 学习备份保存。

译后对照数字、代码标识符、指定术语、可能过短内容及部分新增指标；对可检查的问题最多自动复核一次，仍未解决就保留提示。本地模式可对疑似擅自补出指标的情况使用 Qwen 交叉复核，译文会标出实际所用模型。自动检查不等于语义正确，不能识别所有漏译、增译、逻辑或专业错误。修改原文、译文或上文后会提示重新核对，可按修订英文重译。每段可展开所用上下文、术语和例句归属；相似例句不能当作标准答案。

## 听力训练

开始前勾选“听力训练：先隐藏字幕”，或处理结束后点击一段的“逐段听写”。每段可重放原音，并选择 0.75 / 1 / 1.25 倍速；输入听到的英文后点击“检查听写”。程序按词对齐，列出遗漏、错写和多写，忽略大小写与标点。匹配率只表示与当前英文稿的文字差异，不能当作听力能力评分；识别稿本身可能有误，核对后可修订。

训练前已看过字幕、主动查看参考稿，或查看答案后再次修改，均标为对照练习。“AI 听力解析”调用当前所选内置模型或 API，解释本段句意、关键词和语法。AI 仅收到文字稿，不能诊断原音的连读、弱读或发音。解释可能有误，请结合原音核查。

“我的听力练习”保留最近 200 次参考稿、听写、文字差异和是否看过提示；这些记录会保存并纳入 JSON 备份。原音只在本次窗口内保存，采样缓存约 48 MB，超过后释放最早的原音，单段本身超过缓存上限时不缓存该段原音，文字保留；关闭窗口或清空听译后无法再回放旧原音。

## 可选的断句模型训练

展开“断句模型与训练”，选择“用公开语料训练”，或导入自己的 UTF-8 TXT（每行一个完整英文句子，至少 300 行不同句子，推荐 1000 行以上，最大 5 MB）。已附带公开语料校验缓存，缺失时从官方仓库下载。训练在本机 CPU 后台进行，可取消；自己的文本不上传。

实际训练的是 65536 维哈希特征的逻辑回归英文句界分类器。语料先按文档或连续句组划分训练、验证、测试，移除跨分区重复句；验证集选择轮次及阈值，测试集用于最终报告和启用门槛。通过门槛才切换新模型，失败或取消时保留当前模型，也可一键恢复内置模型。模型选择和自训练文件加密保存在当前账号内，包含在加密账号备份中，不包含在明文 JSON 学习备份中。

“导出训练报告”可查看数据来源、划分、句数、算法、F1、精确率、召回率和保守阈值指标。这些只是英文文本测试集上的句界指标，不是语音识别准确率或学习效果；重复语料、大小写和学科差异都会影响实际表现。文本不能替代音频训练，本功能没有微调 Hy-MT2、Whisper、Silero 或 Qwen。

## AI 伴学

左侧独立的“AI 伴学”支持粘贴原文、选择已保存的资料、导入可选中文字的 PDF / UTF-8 TXT，以及接收听译英文。已有资料的原文默认收起，需要修改时展开。

可针对资料提问、解释难句或出题自测。长文只选取部分原文；“参考范围”可改选段落，回答下可展开本次参考原文。最近四次问答随资料保存，最近两次可作为追问背景。回答可能有误，不应直接当作标准答案。可将最新回答放入批注，核对修改后保存。

PDF 限 20 MB，TXT 限 300 KB，单份资料最多 10 万字符，资料库最多 50 份、原文合计约 30 万字符。扫描 PDF 暂不支持 OCR；双栏、表格、公式和脚注提取后需核对文字顺序。

原“资料学习”页面、全文翻译 / 提词练习入口及局域网手机录入已移除。已有资料、问答、批注和词库保留，可在 AI 伴学及词库中继续使用，也会随 JSON 备份迁移。

## 本地与 API

英语语音识别使用内置 Whisper tiny.en int8 模型，主要面向英语。中文翻译使用内置 Hy-MT2 1.8B Q4_K_M，伴学与听力学习解析使用 Qwen3 1.7B Q4_K_M。模型在 CPU 上本地运行，录音和资料不因本地推理而外发；首次使用自动加载，空闲五分钟后释放模型内存。软件原有新闻与在线朗读仍按各自设置联网。

听译和伴学都可单独选择 API，并共用“API 服务设置”。填写兼容 Chat Completions 的 HTTPS 接口、模型和密钥；地址与模型保存，密钥只存在当前窗口内存中。API 听译在确认后发送当前英文、相邻已完成中英片段、匹配术语和公开参考例句；有问题时可能再复核一次。听力解析发送本段英文。原始录音仍在本地识别，开始前会显示服务商并确认，可能产生费用。伴学 API 会发送本次参考原文、问题与最近问答。

## 词典与数据

“查词”内置 770,610 个扩展离线词条，其中 767,532 条含中文释义；常用 65,000 条支持中文反查。词形会尝试还原原形，专业新词或专名仍可能缺失。

本体验版沿用独立的 WordIsle-Contest-Preview 数据目录，账号文件位于其中 accounts 子目录。新账号的学习记录由桌面主进程加密保存；直接打开 HTML 或旧启动脚本不能进入学习空间。优先通过加密账号备份换机；导入明文学习 JSON 会覆盖当前账号的学习记录，请先备份。公共模型文件不放入账号备份，需保留完整软件文件夹。
