# 词屿图标更新 · 3.9.25-preview

新标志将展开的书页、小岛的弧线与一颗星光组合起来。沿用新版界面的藏蓝、荧光绿、薄荷绿和珊瑚橙，减少文字和细节，便于在任务栏和文件列表的小尺寸下辨认。弧线也像一个微笑，呼应词屿的轻松学习体验。

已统一更新 Windows 可执行文件图标、窗口图标、任务栏分组标识、启动页、登录页、应用侧栏及页面 favicon。Windows 文件属性中的产品名与版本资源也已同步为词屿和 3.9.25；应用内运行版本为 3.9.25-preview。既有账号、学习数据格式及至少 9 位的密码要求继续兼容。

图标源文件为 `resources/app/app/assets/wordisle-icon.svg`，由本项目直接编写矢量图形，未使用其他应用的图标或外部品牌素材。提供 16、20、24、32、40、48、64、96、128、256、512、1024 像素的 PNG，及包含前 10 种尺寸的 Windows ICO。ICO 位于同目录 `wordisle-icon.ico`，便于后续维护快捷方式和安装包。

关闭旧窗口后重新打开完整文件夹中的 `WordIsle.exe` 即可加载全部新图标。若固定到任务栏的旧快捷方式仍显示旧图标，可从新版窗口重新固定；无须删除系统图标缓存。

本次通过 Windows 资源更新 API 修改启动器的图标和版本资源。已逐个核对内嵌的 10 帧图标，并验证修改前后所有非资源 PE 节的 SHA-256 相同，包括程序代码、只读数据与重定位数据。Windows 原生图标提取及修改后程序启动、注册和登录均已验证。桌面与 390 像素布局、登录页、侧栏和启动页图标也已检查。结果见“验证数据/图标更新验证.json”。

原启动器的签名不适用于修改后的资源，新启动器未重新签名，不代表原签发者认可本次修改。原 Electron 和 Chromium 许可证仍保留在完整文件夹中。

实现依据：[Microsoft 图标资源说明](https://learn.microsoft.com/en-us/windows/win32/menurc/about-icons)、[Windows 资源更新 API](https://learn.microsoft.com/en-us/windows/win32/menurc/adding-deleting-and-replacing-resources)、[ImageRemoveCertificate](https://learn.microsoft.com/en-us/windows/win32/api/imagehlp/nf-imagehlp-imageremovecertificate)。
