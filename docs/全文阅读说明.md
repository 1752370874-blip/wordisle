# 词屿 3.9.32 全文阅读

## 如何使用

1. 完整退出旧版，打开本文件夹的 WordIsle.exe，登录后进入“外刊阅读”。
2. 在“全文阅读”打开文章。已有全文直接进入；新条目会读取原网页、确认正文范围并验证完整性，完成后自动进入阅读。
3. 遇到生词点一下，段落下可翻译、讲解和做笔记。完成后可以收藏或记录已读；同一账号下次打开恢复进度。正文缓存及加密的个人快照支持离线阅读。
4. 不能获取正文时可重试或选择“原站阅读全文”。“原站文章”集中展示仅提供原站阅读入口的媒体，不显示 RSS 摘要正文。

## 本版实际内容

真实访问 164 篇文章网页，150 篇完整提取成功，14 篇暂未取得正文；成功正文合计 2747 段、691098 字符。失败条目只有标题与原文地址，不计入全文。原有 52 篇原创和经典材料保留，经典节选的标注不变。数字以本次打包时的数据为准，后续更新会变化。

全文采集配置为 NASA、NOAA、NSF、MIT News；其中实际成功来源与每篇校验收据可查看 resources/app/app/data/reading-news-seed-manifest.json。原站拒绝访问、网络变化、页面结构变化等仍可能造成失败。本次失败情况如实记录在 manifest 与验证报告中。

NPR、Smithsonian Magazine、ScienceDaily、Science News Explores 及其频道保留原站文章链接。未确认允许内置全文的来源不批量打包其正文，也不把其 RSS 摘要交给阅读器假作全文。付费及登录内容留在原站，不绕过访问限制。

## 全文的范围与可靠性

提取发布方已确认的正文 DOM 区域，遍历至末尾，保留正文里的标题、段落、列表、引语、代码及表格文字。提取前后逐字符核对（忽略排版空白），分段后再次核对，并记录正文段数、字符数、SHA-256、采集时间和原文地址。此校验确认所选正文区域没有因词屿的段落上限丢字；不保证原站从未编辑过内容。阅读器提供“核对原文”。

正文最多 400 段、20 万字符；超长段落按句末或空格拆分，保留全部文字。超出总容量、缺少已确认的正文结构、疑似付费墙、正文不足或校验不通过时，整篇失败并转原站，不截断、不返回摘要。文章图片、视频、互动内容及原站页面装饰不包含在文字全文中。

网页由隔离的本地工作线程解析，不执行原站 JavaScript 或下载图片等子资源。RSS 用于发现文章标题和链接，不再把其简介存为可读正文。固定 HTTPS 来源范围和跳转检查仍有效，正文请求不发送账号、学习记录或笔记。锁定或退出账号会取消正在进行的请求。

## 已有数据与更新

旧版摘要不再展示，原来的私人笔记、收藏和剪藏保留。切换至内容不同的新正文时，旧笔记放入“旧版本笔记”，不会直接贴在不相符的新段落上。原站文章卡片可回看旧的个人笔记。后台更新不重绘正在输入的笔记；完整正文不会被 RSS 简介覆盖。

## 来源署名与组件

NASA、NOAA、NSF 内容保留来源与原文入口，并以各页面具体通知为准：[NASA 使用说明](https://www.nasa.gov/nasa-brand-center/images-and-media/)、[NOAA FAQ](https://www.noaa.gov/office-education/outreach-communication/faq)、[NSF](https://www.nsf.gov/)。

MIT News 按其 [Web syndication terms](https://news.mit.edu/terms-of-use) 保留标题、副标题、作者和来源，正文末尾标注“Reprinted with permission of MIT News”并链接原站；未打包图片。来源名称只用于署名。

正文解析使用 jsdom 26.1.0（MIT License）及锁定的依赖，运行组件、package-lock.json 和各组件许可证一并置于 resources/app/app/reading-runtime。没有调用网页自身脚本。

## 已验证

实际 NASA 43 段和 MIT 28 段网页逐段与末段核对；150 篇内置正文逐篇检验段数、字符数和 SHA-256。真实 Windows 程序完成联网抓取与工作线程解析，并检查 390 / 1280 像素布局、MIT 署名、旧摘要退出正文、失败重试。另用明确标为测试的 120 段长文验证第 110 段笔记、位置、收藏和加密重启恢复，回归原有翻译、AI 讲解、生词练习、阅读测验与账号隔离。详见“验证数据/全文阅读验证.json”。
