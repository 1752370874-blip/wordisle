# 词屿 3.9.34：Windows 桌面来源栏目修复

修复目标是本目录中的 WordIsle.exe。桌面端默认全文标签会过滤仅有原站入口的 NPR、Smithsonian 等来源，导致已读入的 RSS 文章在来源筛选后仍显示 0 篇。本版默认显示全部文章，并保留独立的站内全文及原站全文标签；选择来源或点击来源面板的查看按钮时进入该来源的全部条目，重置不兼容的话题和难度。

新增 reading-source-state.js 与固定来源索引 reading-source-index.json，包含从 16 个官方 RSS 实际取得的 297 条去重文章链接。NPR 四个频道各 10 条；其官方纯文字全文链接已抽样验证。既有 150 篇完整正文仍保留；原站文章不使用摘要充当全文。未获授权的 NPR 正文不在软件中批量转载，点击在浏览器打开官方完整文章。

订阅状态按实际缓存计算栏目数量、全文数量和原站入口数，不再笼统宣称正文已更新。空订阅、解析失败不推进成功状态；本地没有条目时不发送会导致空缓存 304 的条件请求。公共缓存与旧版笔记独立保存，旧笔记仍可回看。

完整关闭旧版窗口，再打开原目录的 WordIsle.exe 生效。无需卸载或清空学习记录。
