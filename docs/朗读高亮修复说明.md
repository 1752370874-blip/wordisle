# 词屿 3.9.33：朗读高亮修复

旧版基础朗读规则改变段落左边距，而新版精读段落以 !important 取消横向内边距，两个样式叠加导致高亮竖线贴住段首文字。现为普通、高亮两种状态统一横向边距和内边距，保留 14 像素文字留白；3 像素边线不再与单词相交，激活状态也不再左右移动文字。

在实际 Windows 程序的隔离账号中验证：390、768、1280、1856 像素窗口，暖纸/清爽/夜读三种背景，段落切换、拖动进度、最大字号及真实播放/暂停/继续/停止操作。12 种窗口与背景组合中，首词位置变化为 0、留白为 14 像素，没有横向裁切。笔记仍能编辑保存。详情见“验证数据/朗读高亮修复验证.json”。

完整退出旧窗口，再打开本文件夹的 WordIsle.exe 即可加载新版样式。全文内容、笔记与学习数据保留。
